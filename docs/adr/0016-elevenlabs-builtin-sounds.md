# ADR-0016：內建音效 — 以 ElevenLabs 產生、同一材質成套設計

- 狀態：Accepted（取代 ADR-0008 的「內建音效」一節）
- 日期：2026-10-25（2026-10-26 補充第三套「竹筷」）

## Context

ADR-0008 原本規定內建音效只用 CC0，實作上是程序合成。試聽後使用者認為合成音「太假」，
陸續把「經典」與「毀滅」的部分事件換成作者用 ElevenLabs 產生的錄音，結果同一個 Profile 裡混著合成音與錄音，
材質也不一致（例如「毀滅」開蓋是玻璃、重拍卻是金屬）。

使用者確認的方向（`docs/sound-use-cases.md` §4）：**同一個 Profile 是同一種材質**，各事件的聲音互相呼應，
例如玻璃：開蓋時慢慢碎裂、闔上是一聲短裂、拍打從敲玻璃到整面崩落。辨識度要高，石門與玻璃最直覺。

## Decision

- **所有內建音效都改用 ElevenLabs Sound Effects 產生**，由作者逐一試聽挑選；授權沿用 `LicenseRef-Spank-ElevenLabs`
  （只隨 Spank 散布，不屬於 CC0 或 MIT），逐一列在 `assets/sounds/SOUNDS_LICENSE.md`。程序合成器移除。
- **單一來源**：`assets/sounds/elevenlabs.json` 記錄每個 Profile 的名稱、每個音效的 prompt、事件與長度，
  以及沿用的舊錄音（`kept_sounds`）。
  - `tools/elevenlabs-sounds.py` 依它產生候選（預設每個 3 個）並建立試聽頁。
  - 挑中的候選複製到 `assets/sounds/source/<stem>.wav`。
  - `tools/gen-builtin-sounds` 依同一個檔案打包 `.spankpack`。
- **長度依事件的播放方式決定**（不是越長越好）：

  | 事件 | 長度 | 理由 |
  |---|---|---|
  | 開啟中（`lid_overbent`） | 5 秒 | 連續播放、停手暫停（ADR-0015）；trace 中慢慢打開約 5 秒；持續受力、不要結尾爆炸 |
  | 打開螢幕（喚醒） | 1.5 秒 | 繼續打開到 30° 就會被開啟中蓋過 |
  | 闔上螢幕 | 0.6–0.8 秒 | 睡眠前要播完 |
  | 輕／中／重拍 | 0.5／0.7／1.0 秒 | 單聲部，同級事件播放中會丟掉下一下 |
  | 連擊 | 2 秒 | 高潮，但不拖長 |

- **內建 Profile 只保留兩套**，ID 不變（避免使用者設定與複製的 Profile 失效）：
  - `builtin.destruction` 改名「全玻璃」（All Glass）。
  - `builtin.classic` 改名「地城石門」（Dungeon Gate）。
  - 每套都涵蓋七個事件，每個拍打級別兩個變體。
  - 「哀哀叫」（`builtin.whine`）移除；以它為使用中 Profile 的使用者會退回預設的「全玻璃」。
  - **2026-10-26 補充**：新增第三套 `builtin.chopstick`「竹筷」（Bamboo Chopstick）。螢幕當成一根竹筷：
    開蓋時一絲一絲裂開但不斷、打開是掰開免洗筷、闔上是一聲折斷，拍打從折斷牙籤／筷尖到折斷一整把。
    同樣涵蓋七個事件；預設 Profile 仍是「全玻璃」。三套合計約 6 MB，仍在上限內。
- **不模仿特定作品的音效**：不仿製動畫、遊戲的招牌音效（例如特定機器人的啟動音、遊戲的金幣聲），
  只用類型慣例描述（如「1990 年代動畫機甲」「8-bit 晶片音樂」），旋律一律原創。
  機甲、8-bit 街機兩套已設計並產生過一次，暫放在 `parked_profiles`，尚未內建。
- **總量上限**：內建音效解壓後 < 8 MB（`spank-pack` 測試與產生器都檢查）。

## Consequences

- 每次調整音效都要花 ElevenLabs credits（API 約 11–20 credits／秒），並需要人工試聽；工具會標出幾乎無聲、
  前導靜音過長（打包時會裁掉）與削波失真的候選。
- 舊內建音效（合成音、舊石門／刺耳摩擦／木扣等）不再隨 App 提供；複製自舊內建 Profile 的自訂 Profile
  若引用它們，該事件會變成沒有音效，需要改選。
- 內建音效不再是 CC0；需要 CC0 的散布者得自行替換。

## Alternatives

- **繼續程序合成**：免費、可重現，但聽感被否決。
- **CC0 網路素材**：授權乾淨，但很難找到同一材質、長度剛好的成套聲音；長錄音硬拉長聽起來不自然（`sound-use-cases.md` §4）。
- **保留七套**：試聽後只有石門與玻璃辨識度夠高，其餘先不做。
