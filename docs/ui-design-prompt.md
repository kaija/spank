請幫我設計一個 macOS 選單列小工具的完整 UI（高保真），產品暫名「Spank」（之後會改名，名稱請做成容易替換的文字）。

## 產品是什麼

一個有趣的 MacBook 小 app：
- 使用者打開筆電螢幕時播放音效（例如玻璃破碎），把螢幕闔得很低時播另一種，把螢幕往後掰過頭時播金屬斷裂聲。
- 使用者拍打筆電時，電腦會「哀叫」。依拍打力道分成輕 / 中 / 重三級，短時間連續拍打會觸發「連擊」（例如「不要再打了！！」）。
- 使用者可以用「Profile」（情境）整組切換音效，也可以上傳自己的音效。
- 平常只住在選單列，沒有 Dock 圖示；只有打開設定視窗時才出現在 Dock。

調性：俏皮、有點惡搞，但介面本身要像正經的 macOS 原生 app：乾淨、克制、符合 macOS 設定視窗的慣例。幽默放在文案、插圖、空狀態與音效名稱上，不要讓整體看起來像玩具。

## 平台與通用要求

- macOS 14+，Apple Silicon MacBook。依照 macOS 原生設計慣例（側邊欄設定視窗、系統風格控制元件、SF Symbols 類圖示）。
- 同時提供淺色與深色模式。
- 主要介面語言是繁體中文；英文字串可能長 30–50%，版面要容納得下。
- 設定視窗建議約 760×520，可放大；最小尺寸下不可破版。
- 無障礙：所有控制項都要能用鍵盤操作、有 VoiceOver 標籤；動畫要遵守「減少動態效果」。
- 不需要定義 design token（顏色、字級、間距數值），直接設計畫面即可。

## 核心概念（UI 會用到的詞）

**七種觸發事件**：打開螢幕、闔上螢幕、掰過頭、輕拍、中拍、重拍、連擊。

**Profile**：
- 每個事件對應一組音效，可以掛多個，播放時隨機挑一個。
- 每個事件可以單獨關閉。
- 每個 Profile 有自己的音量。
- 內建三個唯讀 Profile：「毀滅」（玻璃、金屬）、「哀哀叫」（喔、尖叫）、「經典」（吱嘎、悶響）。使用者可以複製成自訂 Profile 再修改。

**自動靜音規則**（各自可開關，任一條成立就靜音）：
- 開會中：麥克風或相機被其他 app 使用時
- 專注模式
- 安靜時段：可設多段，可以跨午夜
- 跟隨系統靜音

**音效上傳限制**：
- 格式：wav、mp3、m4a、aac、flac、ogg
- 每段最長 10 秒、檔案最大 5MB
- 匯入時會自動處理：音量標準化、去除開頭的靜音

**音效包**：副檔名 `.spankpack`，可以匯入或匯出，裡面含音效和授權資訊。

## 需要設計的畫面

### 1. 選單列圖示與下拉選單

圖示要有四種狀態：運作中、已靜音（顯示原因）、已暫停、此機型不支援部分功能。

下拉選單內容：
- 最上面一行顯示狀態，例如「運作中」或「已靜音 — 開會中」
- 暫停 / 繼續
- Profile 子選單：勾選目前使用中的 Profile
- 試聽子選單：列出七種事件
- 設定…
- 結束

### 2. 設定視窗（側邊欄導覽，五個頁面）

**a. Profiles**
- 左邊是 Profile 清單：內建的有唯讀標示，自訂的可以新增、複製、刪除、重新命名。
- 右邊是選中 Profile 的事件對應編輯器，七種事件各佔一列，每列包含：
  - 事件圖示與名稱
  - 啟用開關
  - 已掛上的音效 chips：可試聽、可移除，可以從音效庫拖曳加入
  - 「加入音效」按鈕
- Profile 音量滑桿。
- 內建 Profile 的狀態：無法編輯，並提示「複製後編輯」。

**b. 音效庫**
- 音效清單：名稱、長度、來源（內建 / 自行上傳 / 音效包）、迷你波形、被哪些 Profile 使用。
- 拖放上傳區，也可以選檔上傳。
- 匯入處理中的進度狀態（「標準化音量中…」）。
- 錯誤狀態：格式不支援、超過 5MB、超過 10 秒（截斷提示）。
- 單一音效的操作：試聽、改名、刪除（如果有 Profile 正在使用，要先警告）。
- 匯入 / 匯出 `.spankpack` 的入口。
- 空狀態：要有幽默的插圖和文案。

**c. 感測器**
- **螢幕角度**：
  - 即時角度顯示，做成一個側視的筆電開合角度儀，數字會即時更新。
  - 角度儀上標出三個門檻：打開（約 10°）、闔上（約 20°）、掰過頭（約 120°），可以直接拖曳或用滑桿調整。
  - 進階設定可以展開，包含 hysteresis 和冷卻時間。
- **拍打**：
  - 啟用開關。
  - 即時震動波形，上面畫一條觸發門檻線。
  - 輕 / 中 / 重三個分級門檻（來自校準結果）。
  - 「重新校準」按鈕。
  - 「精準打字模式」開關：說明這需要「輸入監控」權限，以及只記錄有沒有按鍵、不記錄按了什麼。
- **感測器能力狀態**：各感測器的支援情況，有「此機型不支援」的狀態。

**d. 自動靜音**
- 四條規則各一列，每列有開關和一句說明。
- 專注模式那一條要包含權限請求流程，以及權限被拒絕時的狀態。
- 安靜時段編輯器：可以新增多段，要能清楚呈現跨午夜的時段。
- 目前是否正在靜音、原因是什麼的即時指示。

**e. 一般**
- 登入時啟動
- App 總音量
- 語言：跟隨系統 / 繁中 / English
- 自動檢查更新、目前版本、「檢查更新」按鈕
- 「複製診斷資訊」按鈕和「打開 log 資料夾」
- 隱私說明：不收集任何資料

### 3. 首次啟動 Onboarding（獨立小視窗，多步驟）

1. **歡迎頁**：一句話介紹，附幽默插圖。
2. **螢幕角度展示**：即時顯示目前角度，邀請使用者動一下螢幕試試，並播放示範音效。
3. **選擇預設 Profile**：三張內建 Profile 卡片，每張都可以試聽。
4. **拍打功能介紹**：可以選擇「啟用」或「稍後再說」。
5. **校準精靈**：依序請使用者輕拍、中拍、重拍各一次，再打字 5 秒。
   - 每一步都要有即時波形、偵測成功的回饋，以及「重來」選項。
   - 失敗或逾時要有對應狀態。
6. **完成頁**：提示 app 住在選單列，並指出圖示的位置。

### 4. 其他對話框與狀態

- 匯入 `.spankpack` 的預覽對話框：包名、作者、授權、音效清單、是否一併建立 Profile，以及驗證失敗的狀態。
- 刪除確認對話框。
- 新版本可用的提示。
- 觸發時的回饋（選用）：選單列圖示可以有一個短暫的小動畫，例如被打時抖一下。動畫要遵守「減少動態效果」。

## 交付內容

- 以上所有畫面的淺色與深色版本。
- 關鍵元件的狀態變化：開關、音效 chip、拖放區（hover / 拖入中 / 錯誤）、校準步驟（等待 / 偵測中 / 成功 / 失敗）。
- 空狀態、載入狀態、錯誤狀態、權限被拒絕的狀態。
- 簡短的互動說明：拖曳行為、即時更新的元素、視窗關閉後的行為（縮回選單列）。
- 請使用真實感的範例資料，例如音效名稱「玻璃碎裂 01」「金屬斷裂」「喔！」「救命啊」，Profile 名稱「辦公室安靜版」。
